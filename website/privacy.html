Privacy

This website is a set of static pages on GitHub Pages. It uses no analytics, no cookies, no fonts or scripts from other sites. GitHub, which hosts it, keeps its own server logs under its privacy statement.

The app

JARVIS has no account, no server and no telemetry. It never sends your face, voice, words or files anywhere.

  • Stored on your Mac, encrypted (AES-256-GCM, key in the macOS Keychain): face and voice embeddings, notes, alarms, events, memory, chat history (30 days by default) and the security log.
  • Never stored: camera frames, photos, audio, and speech that wasn't addressed to the assistant (it is dropped right after transcription).
  • Offline by default: the backend refuses every internet connection. The only exception is the model download you start on first run, which can reach only the hosts that publish the models.
  • Ollama runs the language model as a separate local program. Its connections are shown in the app's Privacy view.
  • Optional Apple sync writes events and notes into Apple Calendar and Notes only if you turn it on. What Apple does with those apps' data is up to your iCloud settings.

Your control

The Privacy view lists every kind of stored data with its size and age. You can export a readable copy, delete any part of it, or factory-reset, which also deletes the Keychain key so nothing left on disk can be decrypted.
