Privacy

  
What stays.What never exists.

  
Biometrics can't be changed if they leak, so they never leave the Mac and are never stored as pictures or recordings.

  

    
Kept, encrypted
  • Face and voice embeddings (numbers, not images or audio)
  • Notes, alarms, events, memory and chat history
  • A security log of blocked attempts

    
Never stored
  • Camera frames or photos
  • Audio recordings
  • Speech that wasn't addressed to the assistant

  

  

    
Offline by default
The engine refuses every internet connection. The only exception is the model download you start on first run.

    
Local-only API
Bound to 127.0.0.1 with a fresh random token each launch.

    
Yours to delete
A privacy dashboard shows every kind of data with its size and age. Export or erase any of it.

    
Honest limits
A replayed voice can pass voice checks, so acting also needs your live face. Threat model.
