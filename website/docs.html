Quick start

  1. Download the .dmg from the latest release and drag JARVIS to Applications.
  2. Open it once, then System Settings → Privacy & Security → Open Anyway (the app is signed but not notarized).
  3. Let it download its models, install Ollama when it asks, then follow setup: your name, its name, a face scan and six voice phrases.
  4. Say its name, then what you want: "FRIDAY, set a timer for five minutes."
