# Command-routing corpus: how spoken requests should be understood.
#
#   route | expected | what the owner says
#
# route     fast  understood instantly by jarvis/llm/fastpath.py with exactly these actions
#           llm   the fast path must pass it on; the language model should produce these tools
#           gap   should be instant but isn't yet (a known gap; the test is a strict xfail,
#                 so it fails once fixed and the line can become "fast")
# expected  tool(key=value, ...) joined by " + ", or reply=time / reply=date / reply=<words the
#           answer contains> (answered directly),
#           or none (chat or a refusal: no tool). For "llm" lines only the tool names are checked.
#
# The clock is Sunday 27 September 2026, 16:30. Installed apps: see APPS in test_routing_corpus.py.
